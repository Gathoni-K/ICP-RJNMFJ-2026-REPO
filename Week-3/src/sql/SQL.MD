# Database Setup

This folder contains SQL scripts for setting up the database.

## How to use

1. Go to [Supabase Dashboard](https://app.supabase.com)
2. Open your project
3. Go to SQL Editor
4. Copy the contents of `01_create_tables.sql` and paste it into a new query
5. Click "Run"
6. (Optional) Run `02_add_test_data.sql` to add sample data

## Files

- `01_create_tables.sql` - Creates the students and grades tables
- `02_test_data.sql` - Adds sample data for testing
